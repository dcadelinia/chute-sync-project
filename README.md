# Chute Sync Pit-Crew Challenge System

Operational Framework and EdgeAI Telemetry Architecture powered by **Odynex Axis Logistics LLC**. This system handles live asset coordination pipelines, 3D spatial computing telemetry, and high-velocity bio-logistics event mechanics.

## ⚙️ Event Mechanics Managed
1. **Load the Beast** (1,200 lb animal gate stabilization metrics)
2. **Set the Rigging** (Bareback/Saddle tension status verification)
3. **The Flank Pull** (Flank safety strap positioning windows)
4. **Mount & Clear** (Ballistic dummy drop alerts & countdown buzzer timestamps)

## 🚀 Quick Start Deployment

### Local Development
```bash
pip install -r requirements.txt
python -m uvicorn src.main:app --reload
```
The application will run locally at `http://localhost:8000`.

### Containerized Deployment
```bash
docker build -t chute-sync-system .
docker run -p 8000:8000 chute-sync-system
```
